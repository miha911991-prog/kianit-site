КИАНИТ — файлы сайта
====================

Состав:
- index.html — главная страница (светлый дизайн, 6 товаров с Ozon, без цен)
- logo.png — логотип с прозрачным фоном (исправленный)
- logo-yellow.png — версия в палитре сайта (#FFD500 / #111111)
- favicon.png — иконка вкладки (крупная эмблема логотипа)

Запуск: распакуйте всё в одну папку и откройте index.html двойным кликом.
Публикация: загрузите ВСЕ файлы в корень хостинга (public_html).

Фото товаров: скачайте фото с карточек Ozon, назовите foto1.jpg ... foto6.jpg
и положите рядом с index.html. Пока фото нет — видны эмодзи-заглушки.

Заменить перед публикацией: телефон, e-mail и адрес (комментарии ВСТАВИТЬ СЮДА).
